# Learning_Python_Powerful_Object_Oriented_Programming_6th_Edition

This is a book written by Mark Lutz, published by O'Reilly. (2025)

In the past, I have tried to learn Python in a few different ways. I have watched YouTube videos, listened to podcasts, purchased a few books, and have never really come away with a good method for learning. I even went as far as attending Python meetups and meeting someone to show me and look at my code. I never really stuck with it, and it shows in my knowledge.

My goal is to learn Python with no preconceptions other than a passing knowledge. I plan to take notes using Markdown during this process, as well as provide code within the repository. I want to be detailed and show an understanding of the language.
